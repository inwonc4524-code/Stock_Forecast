# 📈 개별종목 추천 봇

매일 아침(한국시간 화~토 오전 7시 13분쯤) 한국·미국 회사 146개를 **테마별로** 분석해서
**휴대폰으로 요약 알림**을 보내고, **웹 대시보드**에 전체 순위를 올려줍니다.
ETF 추천 봇과 같은 방식인데, 개별 회사용으로 **재무지표(PER·PBR·ROE·이익 성장)**와 **실적발표일**이 더해졌어요.
대시보드는 **📅 요즘 추천**과 **🌱 오래 꾸준히 오른(1주~20년)** 두 화면이 있고, 각각 **전체 · 🇰🇷 한국 대표 · 🇺🇸 미국 대표 · 🧬 나스닥 바이오 · 🔋 2차전지 · ⚡ 전고체·ESS · 🏭 AI 전력 · 🤖 로봇** 테마 탭으로 볼 수 있어요 (주식뉴스알림과 같은 테마).

## 무엇을 기준으로 골라주나요?

점수는 **같은 나라 회사끼리** 비교해서 매겨요. (한국과 미국은 PER 같은 숫자의 보통 수준이 달라서)

| 카드 | 기준 |
|---|---|
| 🏆 오늘의 추천 TOP 5 | 상승 흐름 45% + 안정성 25% + 재무 30%. 과열(RSI 75 이상)이거나 적자면 감점 |
| 🚀 쑥쑥 | 1·3·6개월 수익률이 좋고, 200일 평균선 위에 있는 종목 |
| 🎢 쉬는 중 | 200일 평균선은 오르는 중인데, RSI가 40 미만이거나 1년 고점보다 10% 넘게 빠진 종목 (적자 회사 제외) |
| 🐢 꾸준 | 변동성·최대낙폭이 작고, 6개월 수익률이 플러스인 종목 |
| 💎 실속 | PER·PBR이 낮고 ROE·이익 성장률이 높은 흑자 회사 |
| 📢 곧 실적발표 | 14일 안에 실적발표가 있는 종목 (휴대폰 알림에는 7일 안 종목) |

재무지표가 비어 있는 종목은 상승 흐름 60% + 안정성 40%로만 계산해요.

> ⚠ 과거 가격과 재무 자료로 계산한 참고 지표예요. 앞으로의 수익을 보장하지 않으며 투자 권유가 아닙니다.
> 개별 종목은 ETF보다 훨씬 크게 오르내리니 한 종목에 몰아서 사지 마세요.

## 설치 방법 (코딩 필요 없음, 약 10분 — ETF 봇과 똑같아요)

### 1. GitHub에 새 저장소 만들기
1. github.com 접속 → 오른쪽 위 **+** → **New repository**
2. 이름: `Stock_Forecast` (아무거나 괜찮아요) → **Public** 선택 → **Create repository**

### 2. 파일 올리기
1. 저장소 화면에서 **uploading an existing file** 클릭
2. 받은 zip을 푼 폴더 안의 파일을 **전부** 끌어다 놓기
   (`.github` 폴더도 꼭 포함! 안 보이면 맥은 Finder에서 `Cmd+Shift+.` 로 숨김 파일을 보이게 하세요)
3. **Commit changes**

### 3. ntfy 알림 연결
**Settings → Secrets and variables → Actions → New repository secret**
- Name: `NTFY_TOPIC`
- Secret: 휴대폰 ntfy 앱에서 구독한 주제 이름

ETF 봇과 같은 주제를 넣으면 한 곳에서 같이 받고, 따로 받고 싶으면 ntfy 앱에서 새 주제(예: `inwon-stock-8m2x`)를 하나 더 구독해서 그 이름을 넣으세요.

### 4. 봇이 결과를 저장할 수 있게 허용
**Settings → Actions → General** → 맨 아래 **Workflow permissions** →
**Read and write permissions** 선택 → **Save**

### 5. 첫 실행
**Actions** 탭 → 왼쪽 **개별종목 추천 봇** → **Run workflow** → 3~5분 뒤 휴대폰에 알림 도착 🎉
(종목마다 재무지표를 따로 받아와서 ETF 봇보다 조금 오래 걸려요)

### 6. 대시보드 켜기 (첫 실행 후에)
**Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, 폴더: `/docs` → **Save**
1~2분 뒤 `https://내아이디.github.io/Stock_Forecast/` 에서 대시보드가 열려요.

## 종목 바꾸기
`stocks.csv` 파일을 GitHub에서 열고 연필(✏️) 버튼으로 수정하면 돼요.

- 코스피: 종목코드 뒤에 `.KS` (예: `005930.KS` 삼성전자)
- 코스닥: 종목코드 뒤에 `.KQ` (예: `196170.KQ` 알테오젠)
- 미국: 티커 그대로 (예: `AAPL`). 점(.)이 들어간 티커는 하이픈으로 (예: `BRK-B`)
- `market` 칸에 `KR` 또는 `US`, `category` 칸에는 하는 일을 적어요.
- `theme` 칸에 테마를 적어요: `kr` 한국 대표, `us` 미국 대표, `bio` 나스닥 바이오, `bat` 2차전지, `ess` 전고체·ESS, `power` AI 전력, `robot` 로봇. 여러 테마면 `|`로 이어요 (예: `kr|bat|ess`).
- 코스피·코스닥을 반대로 적어도 봇이 알아서 한 번 더 찾아봐요.
- 파일을 저장하면 봇이 바로 한 번 실행돼요.
- 상장한 지 1년이 안 된 종목은 계산에서 빠져요.
- 지금 목록은 2026년 기준 시가총액 상위 종목이에요. 순위가 바뀌면 Claude에게 말해주면 업데이트해드릴게요.
